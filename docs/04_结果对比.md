## 5. 物理约束项的反常表现（本复现最重要的发现）

论文的核心卖点之一是物理约束把总 WAPE 从 6.98%（LE-DeepONet，纯数据）压到 3.12%。
本复现得到的结论相反：**开启物理残差后精度显著变差**。

| 配置 | 总 WAPE | 说明 |
| --- | --- | --- |
| 物理项关闭 | 18.90 | 同一套网络、同样的迭代数 |
| 物理项开启，w_phy = 0.003 | 27.20 | 三个权重扫描 |
| 物理项开启，w_phy = 0.01 | 25.35 | 三个权重扫描 |
| 物理项开启，w_phy = 0.03 | 35.23 | 三个权重扫描 |

三点观察：
1. 权重从 0.003 扫到 0.1，没有任何取值能追平“关闭物理项”，因此不是权重没调好；
2. 残差本身能压下去（`phy_T` 从 1e-1 降到 7e-3），说明网络确实被拉向了 PDE 解，
   但这个解与本仓库求解器生成的标签存在系统性偏差；
3. 最可能的偏差来源：`physics.py` 的化学反应速率用**电芯平均温度**的集总形式
   （`c` 与 `Gas` 都是标量，见 `T_mean_now = T.mean(axis=1)`），而 `losses.py` 的残差逐节点
   用局部温度算速率。两者是同一物理过程的两套离散，在反应加速段可差一个数量级。
   论文的 COMSOL 参考解本身就是逐节点求解，不存在这个不一致。

修复方向（二选一，改动都很小）：把求解器改成逐节点动力学 `c` (B, n_r)、`Gas` (B, n_r)；
或把残差里的速率也换成集总形式（需额外输入电芯平均温度，会削弱物理一致性）。
前者更正确，约 30 行改动，重生成数据 5 s，重训 20 min。

## 6. 误差来源拆解

* 峰值温度已经优于论文：本复现 AREP_T 0.80 / 0.87 / 0.91 / 1.53 %（val/test1/test2/test3），
  论文 Table 6 为 1.15 / 1.68 / 8.75 %。也就是说“会不会烧到多少度”这个问题答得相当准。
* 温度**整段** WAPE 仍差 2–3 倍（1.4–1.8 vs 0.50）：曲线整体偏低 5–10 °C 的系统性偏差，
  而非形状错误（见 `results/fig_case_pile_late.png` 面板 b）。
* 压力与气体偏差最大（WAPE_P ≈ 6、WAPE_Gas ≈ 6.6，论文 0.61 / 0.16）。两者都经过
  `P = Gas·R_g·T/V` 这条通路，误差在指数段被 Gas 放大；且 `Gas` 在窗口前 90% 几乎为 0，
  WAPE 的分母天然偏小，对这种“长时间为零”的物理量并不友好。
* 局部时间窗（`local_window = 300 s`）让主干看到的是相位 τ，在窗口边界处会出现
  图 b 中可见的台阶/锯齿（预测曲线在 300 s 整数倍附近抖动）。论文是“逐段预测”，
  连续铺满 1200 s 时该不连续是方法固有的，可用更大的 `local_window` 或把 τ 换成
  绝对提前量缓解（见 [02_可调参数.md](02_可调参数.md)）。
* `test3`（分布外，升温更慢）比 `test1/test2` 差 2.4 倍，说明外推能力有限，与论文趋势一致。

## 7. 已尝试的改进及其效果

| 手段 | 效果 |
| --- | --- |
| 反应度参数化 `c = 1 − σ(z)`、`Gas = Gas0·σ(z)`，偏置初始化为 −2 | P/Gas 通道误差从 100% 降到 6% 量级（16×） |
| 末段加密采样 `train.d_power = 3`（配点集中到窗口后段的失控陡升处） | 总 WAPE 18.90 → 18.59；**AREP_T 3.83 → 0.80（4.8×）**，RMSE 表面 6.7 → 3.9 K；代价是整段温度 WAPE 0.74 → 1.46 |
| 逐项融合残差（一次 autograd 图同时算 phy/bc/ic） | 每步 0.754 s → 0.412 s（1.8×） |
| NTK 项级自适应权重 | 相对“固定权重”从 71.48 降到 35.75 |

`d_power` 的收益与代价都写在上表里：它把“峰值预测”做好了（这正是热失控预警真正关心的量），
但牺牲了窗口中段的整段精度。若下游只关心峰值与剩余时间，应打开 `d_power`；
若关心整条曲线的形状，则应 `d_power = 1` 并配合更大的网络/更多迭代。

## 8. 结论

1. 论文的**架构**在本仓库完整复现：双算子级联、隐特征锚点、STAN 激活、
   分离主干、NTK 权重、逐项物理残差，均在 `pile_deeponet/` 中有对应实现。
2. 论文的**消融排序**在物理项开启的组别内复现成功：
   `no_ntk` > `no_stan` > `no_latent` > `no_separated`（数值越大越差），与论文一致。
3. 论文的**核心结论（物理项提升精度）未能复现**，原因定位到求解器与残差的
   动力学离散不一致，而不是网络结构或权重设置的问题（§5）。
4. 绝对精度差距（17–36 vs 3.12）主要来自训练预算（2.5k vs 300k 迭代）与
   参考解来源（自研求解器 vs COMSOL）；温度与反应度通道已缩小到 1.4–1.6 倍。

实现差异见 [01_复现说明.md](01_复现说明.md)，可调参数见 [02_可调参数.md](02_可调参数.md)。
