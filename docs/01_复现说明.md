# 复现说明：公式 → 代码 → 偏差

本文档记录复现的完整技术路径：论文的每个公式落在哪个文件、做了哪些工程取舍、
以及**与论文不一致的地方**（这是复现最重要的部分，任何偏差都会影响结果可比性）。

---

## 1. 复现范围

论文有四个可独立验证的部分，本仓库全部实现：

1. **物理模型与数据生成**（Sec. 2.1, 3.1）：1D 径向热失控方程 → 128 个工况的合成数据。
2. **PILE-DeepONet 结构**（Sec. 2.2.1–2.2.3, Fig. 3, Tables 3）：两级 DeepONet 复合。
3. **训练策略**（Sec. 2.2.4, Appendix A）：分离式主干、STAN 激活、编码器跳跃、NTK 权重、无量纲化。
4. **评估**（Sec. 3.3–3.6）：WAPE/AREP、消融、潜空间显著性、提前量与数据量扫描。

**没有**复现的部分：真实电芯热失控实验（Sec. 3.2，需要实验台架）、
CUDA/边缘端推理时延实测（我们只测了 GPU/CPU 单次推理耗时）、
100 次蒙特卡洛噪声不确定性实验（提供了脚本入口但未在主流程中跑）。

## 2. 控制方程与求解器（`pile_deeponet/physics.py`）

### 2.1 方程映射

| 论文 | 代码 | 说明 |
| --- | --- | --- |
| Eq.1 能量方程 | `simulate()` 中 `dT += (q_exo)/rho_cp` 与面通量累加 | 只保留 `Q_exo`，忽略可逆热与欧姆热（论文同样忽略） |
| Eq.2 `Q_exo = H·W·R` | `rate = A*exp(-E/(Rc*(T+273.15)))*c`；`q = H*W*rate` | 单位体积热源 W/m³ |
| Eq.3 `R = -dc/dt` | 解析积分 `c *= exp(-rate*dt)` | 指数积分器，比显式欧拉稳定 |
| Eq.4 表面对流+辐射 | `h_tot = h_heater + h_cool`（加热阶段）| 论文把辐射并入等效换热系数 |
| Eq.5 `dGas/dt = (Gas0-Gas)R` | `gas = Gas0 - (Gas0-gas)*exp(-rate*dt)` | 与 c 同一指数因子（解析解） |
| Eq.6 `P = Gas·R_g·T/V` | `p = gas*Rg*(T_mean+273.15)/free_volume` | `free_volume` = 罐体体积 − 电芯体积 |
| Eq.30 加热/冷却边界 | `S(c)=1 if c>=0.1`，`h_eff = S·h_heater + h_cool` | `c_off=0.1` 对应论文"反应物耗尽即断电" |

### 2.2 离散

* 空间：**有限体积**，31 个节点（中心→表面），与论文一致；节点控制体积 `vol_i`、
  界面面积 `a_mid`、表面面积 `a_surf` 由 `_grid(cfg)` 给出。
* 时间：显式格式 + `dt=0.05 s`（论文未给步长；CFL 自查：`k·dt/(rho·cp·dr²) ≈ 0.04 ≪ 0.5`）。
* 集总动力学：`c`、`Gas` 用**体平均温度** `T.mean()` 计算反应速率——论文把电芯当作
  单等效化学组分，这是与之一致的处理；若逐节点算速率，会出现 `c` 与 `T` 形状广播错误
  （复现时踩过，见 §9）。

### 2.3 参数校准（重要偏差）

论文 Table B1 给出 `A=3e7 s⁻¹, H=1.6e5 J/kg`。用这两个值我们的求解器给出峰值 **334 °C**
（论文参考算例为 **412.7 °C @ 2647 s**）。原因是论文的 COMSOL 模型与我们的 1D 简化模型在
换热面积、等效体积、辐射项上并不等价。

因此按论文自己的说法（"key parameters were adjusted based on experimental data"），
我们做了二维扫描后取 **`A=2.0e7 s⁻¹`，`H=2.6e5 J/kg`**，得到：

| 量 | 论文 FEM | 本求解器 |
| --- | --- | --- |
| 峰值温度 | 412.7 °C | **416.5 °C** |
| 峰值时刻 | 2647 s | **2640 s** |
| 峰值压力 | 291.5 kPa | **362 kPa** |
| （参考算例：升温 2600 s，h_cool=7） | | |

温度误差 < 1%，压力偏高约 24%（压力对 `Gas0`、自由体积、平均温度都敏感，
论文未给罐体体积，我们取 `canister_volume = 3.95e-3 m³` 使 4680 电芯装入
100 mm 半径 × 105 mm 高的密封罐后自由体积合理）。

> **这一条决定了"绝对数值不可比"**：我们的训练标签全部来自这个求解器，
> 所以 WAPE 只在"相对论文趋势"的意义上有意义。

## 3. 无量纲化与局部时间分段（Eq.7–8, 26–29）

* `d`（归一化提前量）∈[0,1]，物理时间 = `lead_time · d`，`lead_time = 1200 s`。
* 局部时间窗 `L = local_window = 300 s`，`τ = (d·lead_time) mod L / L`（`model.py:178`）。
* 残差用论文 Eq.27–29 的尺度：`sT = ρc_p·ΔT/lead_time`，`sC = 1/lead_time`，
  `sG = Gas0/lead_time`，`sBC = sT·R`（`losses.py:29–35`）。
* 归一化：`x° = x/R`，`T° = (T - T_min)/(T_max - T_min)` 用于分支输入 `u2/u3`；
  输出侧用 `T = T_min + ΔT·σ(·)` 保证物理范围 `[20, 520] °C`。

**分支输入构造**（`data.py::_window_features`）——这是论文里最容易误解的一点：

* `u1 = h_cool / 20`（冷却能力，1 维）
* `t_thr`：表面温度首次达到 **120 °C** 的时刻
* `u2`：`t_thr` 之前 **31 个表面温度样本**（间隔 30 s，共覆盖 900 s）
* `t_d`：预测窗口起点 = `t_peak − lead_time`（峰值前 1200 s）
* `u3`：`t_d` 之前 **11 个表面温度样本**（间隔 30 s）
* `u4`（仅预测算子）：隐特征在锚点 `d ∈ {900, 990, 1110, 1200} s` 处的 4 个标量

> 论文只说"prediction starts at t=1500 s"，实验算例中 `t_d ≈ 1490 s`（峰值 2690 s）。
> 我们把 `t_d` 定义为**每工况峰值前 1200 s**，这样每条工况都有完整的 1200 s 预测窗，
> 与"提前量 600/900/1200 s"的扫描实验一致。

## 5. 网络结构（`model.py`, Fig. 3, Table 3, Appendix A）

```
u1(1) ─┐                          ┌─ trunk_x(x)  ─┐
u2(31)─┤  3 分支 × 编码器         │               ├─ 乘积集成 → 隐特征 X̂_F (q=300)
u3(11)─┘      ↓                   └─ trunk_d(d)   ─┘
        Ĝ_F（隐特征算子）→ 每个场取 q/3 个通道
                              ↓ u4(4)
u1,u2,u3,u4 ─ 4 分支 × 编码器 ─ 2 主干(x, (d,τ)) ─ 乘积集成 → T, c, Gas
        Ĝ_P（预测算子）                                    ↓ Eq.6
                                                          P
```

* **编码器 + 跳跃**（Appendix A, Eq.A.1–A.6）：`EncoderMLP` 第一层把输入线性编码，
  之后每层是一个**门控残差**：`z = (1-g)·e + g·act(mix(z))`，`g = σ(gate(z))`。
  这是对论文"把编码 E_u / E_y 通过门 H 注入每一层"的实现。
* **乘积集成**（Eq.10–11）：每个分支网络输出 (N, q)，主干输出 (N, q)，逐元素相乘后
  在 `q/3` 个通道上求和，三个场分别用 `K_T, K_c, K_Gas` 三段通道。
  `combine="sum"`（默认）与 `combine="product"`（论文原始形式）都可切换。
* **STAN 激活**（Eq.21–22）：`φ(x) = (1+βx)·tanh(x)`，β 逐神经元可学，初值 0.1。
* **分离式主干**（Eq.19–20）：空间坐标与时间坐标各走一个主干网络，避免
  "单主干吃 (x,d) 拼接"带来的链式求导耦合。
* **输出参数化**（**偏差**）：论文直接把场的线性组合作为输出；我们对其加了
  物理约束 `T ∈ [20,520]`、`c ∈ [0,1]`、`Gas ∈ [0, Gas0]`。
  其中 `c` 和 `Gas` 用**反应度** `ξ = 1 − c` 参数化（`model.py:193`），
  否则 sigmoid 会把 `c` 钉在 1、`Gas` 钉在 0（复现时的真实故障，见 §9）。

## 6. 损失与训练（`losses.py`, `train.py`, Table 4）

论文 Eq.12：`L = Σ_X [L_phy,X + L_BC,X + Σ L_IC,X]`，X ∈ {T, c, Gas}。

| 项 | 代码 | 权重（默认） |
| --- | --- | --- |
| 数据项（混合监督） | `terms()["data_T/c/gas"]` | `w_data=1`, `w_data_T/c/gas=1` |
| 物理残差 Eq.16–18 | `terms()["phy_T/c/gas"]` | `w_phy=0.1`，800 迭代后线性升到 1 |
| 边界 Eq.30 | `terms()["bc_T"]` | `w_bc=1` |
| 局部窗初值 | `terms()["ic_T/c/gas"]` | `w_ic=1` |
| NTK 自适应权重 Eq.23–24 | `Trainer.estimate_weights()` | 每 1000 迭代，clip [0.05,20] |

**NTK 的实现偏差**：论文 Eq.24 是**逐配点**的 `λ_j = sqrt(max_k H_kk / H_jj)`，
需要对 9000+ 个点各算一次梯度内积；我们改为**逐损失项**：
`λ_k = sqrt(mean_trace / trace_k)`，`trace_k = Σ_θ (∂L_k/∂θ)²`。
这是"按项平衡梯度量级"的近似，计算量从 O(N_points·N_params) 降到 O(10·N_params)，
代价是失去逐点自适应（论文报告 NTK 占 47% 训练时间，我们用不到 3%）。

**其他超参**：Adam，lr=1e-3，每 2000 迭代 ×0.1（论文相同），
每步采样 512 数据点 + 512 物理点 + 256 边界 + 256 初值点（论文 512+1024+512）。

## 7. 评估（Eq.31–34）

* `WAPE = Σ|y−ŷ| / Σ|y| × 100`（`evaluate.py::wape`）
* `AREP = |y_peak−ŷ_peak| / y_peak × 100`
* `RMSE`、`MAE` 分别统计表面节点、中心节点与全场
* `wape_total = WAPE_T + WAPE_P + WAPE_c + WAPE_Gas`（与论文 Table 5 的口径一致）

## 9. 复现过程中踩到的坑（对二次开发者有价值）

1. **形状广播把"逐样本监督"变成"两两配对"**
   `t_d` 是 `(N,)`、`d` 是 `(N,1)`，`t_d + d·lead_time` 会广播成 `(N,N)`，
   于是 `T[cond, ti, xi]` 取出 `(N,N)` 的目标值，损失矩阵是 `(N,N,D)`。
   现象：loss 恰好等于标签方差，无论换什么架构、数据量、激活函数都"卡住不动"。
   修复：`batch.py::time_index` 里 `self.t_d[cond].unsqueeze(-1)`。
   **诊断技巧**：打印 `batch["T"].shape`，它必须是 `(N,1)`。

2. **sigmoid 输出头把 `c`/`Gas` 钉死**
   `c` 在窗口内几乎恒为 1、`Gas` 几乎恒为 0（热失控只在窗口末尾爆发）。
   `σ(z)` 一旦被推到 ±10 附近梯度就消失，模型永远停在 `c=1, Gas=0`。
   修复：用反应度 `ξ = 1−c` 参数化，并把 `b_c, b_g` 初值设为 −2（sigmoid 的线性区）。

3. **隐特征算子与预测算子共用同名属性**
   最初把 `u4` 的锚点也传成 `d`，导致 `latent` 与 `pred` 的 `tau` 不一致；
   用 `_trunk_inputs(x, d, tau)` 统一后消失。

4. **`torch.load` 需要 `weights_only=False`**（checkpoint 里存了 dataclass 配置）。

5. **文件名不能叫 `bisect.py`**：会遮蔽标准库，`import torch` 报
   `ImportError: DLL load failed while importing _C`。

6. **`nn.Parameter(t.zeros(1).cuda())` 是非叶子张量**，优化器会报
   `ValueError: can't optimize a non-leaf Tensor`；应写 `nn.Parameter(torch.zeros(1, device="cuda"))`。
