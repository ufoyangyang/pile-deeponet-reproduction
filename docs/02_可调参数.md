# 可调参数与改进方向

所有可调项集中在 **`pile_deeponet/config.py`**（四个 dataclass），
命令行只暴露了最常用的 ablation 开关（`scripts/train.py --no-physics/--no-latent/...`）。
下表的"影响"来自本仓库的实际实验与论文的敏感性分析，可作为调参起点。

---

## 1. 物理参数 `PhysicsConfig`

| 参数 | 默认 | 含义 | 影响 / 建议 |
| --- | --- | --- | --- |
| `rho`, `cp`, `k` | 2790, 990, 0.7 | 等效密度 / 比热 / 径向导热 | 决定热扩散时间尺度；`k` 越小表面与中心温差越大（论文 Table 8 用它解释 5 °C 的中心误差） |
| `E`（活化能） | 99000 J/mol | Arrhenius 指数项 | **最敏感**：论文报告 ±5% 就明显改变峰值时刻。做参数辨识时优先标定它 |
| `A`（指前因子） | 2.0e7 s⁻¹ | 反应速率常数 | 论文 ±30% 影响很小（指数项主导）；但在我们的 1D 模型里它直接决定"什么时候开始自加速" |
| `H`（生热焓） | 2.6e5 J/kg | 单位质量反应热 | 主要控制**峰值温度**；论文里 `H` 与 `W` 是同一量纲组合 |
| `W`（反应物密度） | 2291.3 kg/m³ | 单位体积反应物质量 | 与 `H` 相乘出现在热源里，二者**不可分辨**，只能标定乘积 |
| `Rc` | 8.314 J/(kg·K) | 论文印刷值（实际应为 J/(mol·K)） | 与 `E` 强耦合；换体系时务必同时重标定 |
| `Rg` | 189 J/(kg·K) | 气体常数（按质量） | 只影响压力幅值 |
| `Gas0` | 8.8e-3 kg | 满产气量 | 只影响压力幅值；论文 LFP 4680 取 8.8 g |
| `radius`, `height` | 0.023 m, 0.080 m | 4680 电芯（46 mm × 80 mm） | 换电芯规格时改这两个 |
| `canister_volume` | 3.95e-3 m³ | 密封罐体积（论文未给，**假设值**） | 与 `Gas0` 一起决定压力；做实验对标时优先标定它 |
| `T_init/target/cool` | 35 / 270 / 35 °C | 初温 / 加热目标 / 冷却液温度 | 对应论文 Table 2 |
| `h_heater` | 200 W/(m²K) | 加热片等效换热系数（论文未给，**假设值**） | 控制升温速率；`S(c)` 在 `c<0.1` 时把它关掉 |
| `c_off` | 0.1 | 断电阈值 | 就是论文 Eq.30 的开关判据 |
| `n_r` | 31 | 径向节点数 | 论文用 31；降到 15 精度略降但求解快 4× |
| `dt`, `save_dt` | 0.05, 2.0 s | 求解步长 / 存储间隔 | `dt` 受显式格式 CFL 限制；`save_dt` 决定数据集大小 |

**换体系**：论文 Appendix E 还给了 **NMC 软包**参数
（`rho=2201, cp=995, k=0.84, E=1.54e5, A=2.244e12, H=4.24e5, W=530, Gas0=0.25 g`），
在 `config.py` 里直接替换即可复现"换个化学体系"的实验。

## 2. 工况与数据划分 `SplitConfig`

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `ramps_train` | 2100→3000, 步长 45（21 个） | 升温时长；对应 4.3–6.7 °C/min，落在 UL 9540A 的 4–7 °C/min 区间 |
| `h_cool` | {7,10,13,16,19} | 冷却能力（等效换热系数） |
| `ramps_ood`, `h_ood` | 3100→3300 / {7,13,19} | 分布外测试集（更快升温） |
| `exp_condition` | (2600, 7) | 与真实实验对应的工况（测试集 2） |

**可做的实验**：把 `ramps_train` 加密到步长 15 s（63 个升温 × 5 = 315 工况）看数据量收益；
或反过来把训练集砍到 24 工况复现论文的 data-scarcity 曲线（论文：84→24 工况时
PILE 总 WAPE 4.13→4.97，而 LE-DeepONet 5.33→6.68，说明物理约束在少数据时更值钱）。

## 3. 模型结构 `ModelConfig`

| 参数 | 默认 | 含义 | 调参建议 |
| --- | --- | --- | --- |
| `q` | 300 | 每个场的隐特征通道数 | 论文 Table 3；减小到 96 精度略降、显存友好 |
| `hidden`, `depth` | 100, 4 | 每个分支/主干网络的宽度与隐层数 | 论文 Table 3 |
| `combine` | `"sum"` | 分支集成的组合方式 | `"product"` 是论文 Eq.10 的原始形式；乘性集成对小信号更敏感，但初期更难训练 |
| `reduce` | `"sum"` | 隐特征合成方式 | `"sum"` 按 `1/√(q/3)` 缩放；`"mean"` 更稳但幅值小 |
| `out_act` | `"linear"` | 编码器输出层激活 | 论文用 sigmoid（Table 3）；我们实测 sigmoid 会让乘积基函数几乎常数，故默认线性，可切回 |
| `stan` | True | 使用 STAN 激活 `(1+βx)tanh(x)` | 关掉即消融项（论文：3.12%→3.94%） |
| `separated_trunk` | True | 空间/时间分离主干 | 关掉即消融项（3.12%→3.83%） |
| `use_latent_operator` | True | 是否使用隐特征算子（两级结构） | 关掉 = PI-DeepONet 基线（论文 3.12%→5.42%） |
| `n_latent_features` | 4 | `u4` 的维度 | 论文扫描 2/3/4/6/11 → WAPE 3.95/3.36/3.12/3.39/3.50（4 最优） |
| `history_len`, `short_len` | 31, 11 | 长/短期历史采样点数 | 覆盖 900 s / 300 s；采样间隔 `sample_dt=30` |
| `t_threshold` | 120 °C | `t_thr` 判据（表面温度首次到 120 °C） | 越小越早预警，但历史窗更容易被噪声污染 |
| `lead_time` | 1200 s | 预测提前量 | 论文扫描 600/900/1200 → 2.50/3.12/3.35；越小越准 |
| `latent_anchors` | (900,990,1110,1200) s | `u4` 的锚点时刻 | 应覆盖"临近峰值"区间 |
| `local_window` | 300 s | 局部时间窗长度 | 论文的时间分段策略；越小越刚性、越大越难优化 |
| `T_min/T_max` | 20 / 520 °C | 温度归一化范围 | 换体系时要跟着改 |
| `gas_ref`, `gas_max` | 8.8e-3 kg | 产气归一化 | 随 `Gas0` 改 |

## 4. 训练 `TrainConfig`

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `iters` | 20000 | 论文 300k（A100 11 h）；20k 在 5090 上约 40 min，精度约差 2–3 倍 |
| `lr`, `lr_decay_every`, `lr_decay` | 1e-3, 2000, 0.1 | 与论文一致 |
| `n_data / n_phy / n_bc / n_ic` | 512 / 512 / 256 / 256 | 每步采样点数；物理点越多残差越稳，显存也越大 |
| `physics_warmup`, `physics_ramp` | 800, 800 | 先纯数据预热，再线性加物理项——**很重要的稳定技巧** |
| `w_data*`, `w_phy`, `w_bc`, `w_ic` | 1, 0.1, 1, 1 | 物理项权重过大时数据拟合会退化（我们实测 `w_phy=1` 时 data_T 从 3e-4 退到 1.4e-3） |
| `use_ntk`, `ntk_every`, `ntk_points`, `ntk_clip` | True, 1000, 32, (0.05,20) | 项级 NTK 权重；`ntk_points` 是估 trace 用的采样点数 |
| `seed` | 0 | 换种子可做误差棒（论文 Table 5 的 ± 就是这么来的） |

## 5. 值得尝试的改进（按性价比排序）

1. **把物理权重交给 NTK 而不是手调**：目前 `w_phy=0.1` 是折中值。若能实现论文的逐点 NTK
   （或更便宜的梯度归一化），可以让物理项在配点稀疏处自动变强。
2. **pressure 直接监督**：目前 `P` 由 `Gas·R_g·T/V` 导出，误差被 `Gas` 与平均温度双重放大。
   若实验能测压力（论文实验确实测了），加一路 `data_P` 会更稳。
3. **自适应时间分段**：固定 `L=300 s` 在热失控爆发段（最后 100 s）分辨率不足；
   按 `|dT/dt|` 自适应加密会显著改善峰值误差。
4. **多保真**：用 1D 求解器产生大批低保真数据 + 少量 3D/实验高保真数据做 co-kriging 式融合。
5. **算子级的迁移**：把 `u1`（冷却能力）扩展成"冷却曲线 + 环境温度"多维输入，
   可以直接用于冷却系统设计优化（见应用方向文档）。
6. **不确定性**：论文用 100 次蒙特卡洛噪声注入给出峰值 95% 区间；工程上更实用的是
   MC-dropout 或 deep ensemble，推理成本只增加常数倍。
